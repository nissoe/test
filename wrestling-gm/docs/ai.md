## בקצרה

- **בלי רמאויות (החלטה 58):**
  - המחשב מקבל אותו תקציב ואותם מתאבקים.
  - הוא לא רואה מידע נסתר, למשל את הכרטיס שלך.
  - הוא משלם על כל דבר כמו השחקן.
  - הקושי בא רק מהחלטות טובות יותר.
- **רמת הקושי קובעת את החוכמה:** ברמה קלה המחשב בוחר בסיסי ועושה טעויות. ברמת עילית הוא משחק כמו שחקן מנוסה.
- **אישיות:** כל מנהל משחק לפי המשפחה של הקלף שלו. מנהל התקפה פוגע ביריבים, ומנהל כלכלה חוסך ומשקיע. כך כל יריב מרגיש אחרת.
- **אותו מנוע:** המחשב הוא "בקר" כמו שחקן מקומי או שחקן מרוחק (החלטה 2), ולכן הוא עובד בכל מצבי המשחק.

## איך המחשב מחליט, לפי תחום

| תחום | מה המחשב עושה |
| --- | --- |
| דראפט | מדרג מתאבקים לפי ערך: פופולריות, ניסיון, מיקרופון ומשכורת. הוא שומר על איזון בין סגנונות ובין טוב לרע, ונזהר לא לחרוג מהתקציב. |
| בניית תוכנית | שם את הקרבות החזקים בפתיחה ובקרב הראשי. הוא מנסה להתאים סגנונות (ענק–קל-משקל, לוחם–מכתש) ולשים טוב מול רע. |
| לוגיסטיקה | בוחר אולם לפי הפופולריות של הרוסטר, כדי לא לשלם על אולם שלא יתמלא. |
| פרומואים | נותן פרומו למי שמדבר טוב. הוא קורא לתיגר כדי לבנות יריבויות לקראת אירוע שיא, ומאמן צעירים. |
| יריבויות | מתזמן יריבויות כך שיגיעו לרמה 4 בדיוק באירוע השיא. |
| קלפים | שומר קלפים חזקים לאירועי שיא ולרגעים קריטיים, וקונה בחנות לפי הצורך. |
| גיוס | מחליף מתאבקים פצועים או עם מורל נמוך. הוא מחפש עסקאות בסקאוטים, ומחתים אגדה כשיש כסף לפני אירוע גדול. |
| טריידים | מציע ומקבל טריידים רק כשהערך קרוב. ברמות גבוהות הוא מנסה לנצל חולשה שלך, למשל רוסטר דל בסגנון מסוים. |
| בקשות | ממלא בקשות כשזה זול, כדי לשמור על המורל. |
| סיבולת | נותן מנוחה למתאבקים עם סיבולת נמוכה, כדי למנוע פציעות. |

## לפי רמת קושי

| רמה | איך המחשב משחק |
| --- | --- |
| קל | בחירות בסיסיות, לפעמים מתעלם מהתאמת סגנונות, משתמש בקלפים באקראי, ולא מתכנן יריבויות. |
| רגיל | מאוזן: מתאים סגנונות וצדדים ומתכנן יריבויות לאירועי שיא, אבל טועה לפעמים. |
| קשה | חכם: כמעט תמיד מתאים נכון, ושומר קלפים לאירועי שיא. |
| קיצוני | חכם מאוד: מתזמן קלפים בדיוק, מתחרה בך על מתאבקים בגיוס, ומגיב למה שאתה עושה. |
| עילית | הכי חכם: משחק כמו שחקן מנוסה, מנצל כל יתרון שהחוקים מאפשרים, ומשתמש בכל הקלפים בזמן הנכון. |

| משפחה | סגנון המשחק של המחשב |
| --- | --- |
| כלכלה | חוסך כסף, בוחר אולמות בזהירות, ומשקיע גדול באירועי שיא. |

| התקפה | פוגע ביריב המוביל בדירוג, קונה קלפי התקפה, ומנסה לחטוף מתאבקים. |
