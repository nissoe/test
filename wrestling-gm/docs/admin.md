## בקצרה

- **כניסה בתקופה א׳ (החלטה 60):**
  - כל אחד יכול להירשם עם מייל, גוגל או אפל.
  - החשבון נשאר במצב "ממתין" עד שאתה מאשר אותו בלוח.
  - עד האישור, המשתמש רואה מסך המתנה ולא יכול לשחק.
- **הלוח מתמקד בניהול משתמשים והרשאות.** אפשר להוסיף סטטיסטיקות, עריכת מספרים ודיווחים בהמשך, אם יתברר שצריך.
- **בתקופה ב׳:** אותו לוח, ובנוסף ההגדרות של הגרסה החינמית (החלטה 8).

## מה יש בלוח

| פעולה | מה היא עושה |
| --- | --- |
| רשימת משתמשים | שם, מייל, תאריך הרשמה, מצב (ממתין, מאושר, חסום) וסוג גישה |
| אישור | המשתמש יכול לשחק |
| דחייה וחסימה | המשתמש לא יכול להיכנס. אפשר לבטל |
| מחיקה | מוחקת את החשבון ואת השמירות שלו |
| הענקת גישה מלאה | פותחת הכול למשתמש, בחינם |
| ביטול גישה מלאה | מחזירה אותו לגרסה החינמית (בתקופה ב׳) |
| אדמינים נוספים | נותנים למשתמש אחר הרשאה לנהל את הלוח |
| התראה על הרשמה חדשה | מייל אליך כשמישהו נרשם ומחכה לאישור |

## מצבי משתמש

| מצב | מה המשתמש רואה |
| --- | --- |
| ממתין | מסך "החשבון שלך ממתין לאישור" |
| מאושר | המשחק, לפי סוג הגישה שלו |
| חסום | מסך "אין גישה" |

**סוגי גישה בתקופה ב׳:** חינמי, רכש, או הוענק על ידי אדמין.
