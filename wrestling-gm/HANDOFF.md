# איך ממשיכים במחשב

כל מה שתכננו נמצא בתיקייה הזו (`wrestling-gm/`) בריפו `nissoe/test`, בענף `claude/sharp-brown-0igbc3`.

## פעם ראשונה
1. מתקינים את אפליקציית Claude למחשב ומתחברים לאותו חשבון.
2. מורידים את הריפו מ-GitHub למחשב (בעזרת Claude עצמו: "תוריד את הריפו nissoe/test ותעבור לענף claude/sharp-brown-0igbc3"), או עם GitHub Desktop.
3. פותחים ב-Claude Code את התיקייה `wrestling-gm` שבתוך הריפו.
4. כותבים: "תקרא את CLAUDE.md, decisions.md ו-HANDOFF.md ותמשיך מאיפה שעצרנו".

## מה Claude במחשב יודע
- `CLAUDE.md` — הקשר הפרויקט וכללי העבודה (עברית, שאלה אחת בכל פעם עם המלצה, היצמדות למקור).
- `decisions.md` — כל ההחלטות שהתקבלו. זה מקור האמת.
- `research-summary.md` — תקציר המחקר על המשחק המקורי.
- מסמך המחקר המלא: https://claude.ai/artifact/Fzmg4pp5hGMkoFbgVDT9hA

## חשוב
- כל עבודה חדשה נשמרת ונדחפת ל-GitHub (commit + push), כדי שגם השיחה בענן וגם המחשב יראו אותה.
- לפני שמתחילים לעבוד, מושכים את העדכונים האחרונים (pull).
- השיחה המקורית (התכנון) זמינה גם היא ברשימת השיחות של האפליקציה.

## מאיפה ממשיכים (מצב בסוף התכנון בענן, 19.11.2026)
**מוכן:** 50 החלטות (`decisions.md`), מסמך אפיון גרסה 0.3 (`docs/gdd.md`), עלויות לשתי התקופות (`docs/costs.md`), רוסטר של 300 מתאבקים (`content/roster.json`, `docs/roster.md`), 20 מנהלים ו-90 קלפי כוח (`content/`, `docs/cards.md`), סקיצות לוגו (`brand/`), מפרט 30 חגורות (`docs/belts.md`).

**המשימות הבאות במחשב, לפי הסדר:**
1. **סגירת 14 ההחלטות הפתוחות** בשאלון (רשימה בפרק "מה עוד פתוח לתכנון" ב-`docs/gdd.md`).
2. **בדיקת סימן מסחרי** ל-LWF ולשמות 5 התוכניות: ארה"ב, אירופה, ישראל, חנויות ודומיין (החלטה 30).
3. **מחקר המספרים של המקור** עם שליטה בכרום: יוטיוב ומדריכים. משלימים את כל ה-"לאמת" (החלטה 23).
4. **אב-טיפוס:** מנוע TypeScript טהור + ממשק בדפדפן, עונה מלאה עם כל הדמויות ותמונות זמניות (החלטה 41).
5. **תמונות:** דיוקנאות וחגורות, אחרי שהאב-טיפוס הוכיח את עצמו.
6. **עיצוב, סאונד, חשבונות, איזון,** ואז תקופה א׳ (דפדפן לחברים ולמשפחה) ותקופה ב׳ (חנויות) (החלטה 40).

**כללי עבודה:** עברית בכל דבר (גם בתיאורי הפעולות), שאלה אחת בכל פעם בחלון בחירה עם המלצה, היצמדות למקור, מסמכים רק בתבנית האחידה, ונתוני המשחק באנגלית ובעברית (אנגלית ראשית).

## מנוע המשחק (engine/) — גרסה 0.1
- TypeScript טהור, דטרמיניסטי (אותו seed = אותה עונה). מתקינים: `cd engine && npm install`.
- `npm test` — 7 בדיקות (RNG, טעינת תוכן, טווח ציונים, דראפט, משבצת לפני אירוע שיא, עונה של 50 ו-25 שבועות).
- `npm run sim -- [seed] [25|50]` — עונה שלמה עם 4 מותגים של המחשב.
- כל המספרים במקום אחד: `engine/src/config.ts` ("מודל עבודה" = יכויל במחקר המספרים).
- יש: דראפט, תארים, ציון קרב ותוכנית, סיבולת, פציעות, מורל, פופולריות, יריבויות, אולמות, כלכלה, אירועי שיא, סוף עונה.
- עוד אין: קלפי כוח, אירועים ובקשות, גיוס וטריידים, קרבות זוגות ומרובי משתתפים בתכנון של המחשב.

## אב-טיפוס שאפשר לשחק (app/) — Expo, ווב
- דף פרטי לשחק בו: https://claude.ai/artifact/MMr6HTV9QSRh7r3GQZjkRN
- הרצה במחשב: `cd app && npm install && npx expo start --web`. בנייה: `npx expo export --platform web` (בסביבה בלי גישה ל-api.expo.dev מוסיפים `EXPO_OFFLINE=1`).
- המנוע והתוכן נטענים ישירות מ-`../engine` ו-`../content` (ראו `metro.config.js`).
- מסכים: פתיחה (מותג, יריבים, קושי, אורך עונה) · דראפט צעד-אחר-צעד · בניית תוכנית (אולם, קרבות, תנאים, תארים, פרומואים, בנייה אוטומטית) · רוסטר · דירוג · תארים · תוצאות · סוף עונה. החלפת שפה אנגלית/עברית עם כיוון מימין לשמאל.
- עוד אין: שמירת משחק, קלפים, אירועים, גיוס, קרבות זוגות, אנימציות ועיצוב סופי.
